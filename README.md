# Tabata-таймер

**Tabata-таймер** — это веб-приложение для эффективных интервальных тренировок по методике Табата. Пользователь может запускать кастомные или готовые тренировочные программы с озвучкой этапов и точным таймингом фаз: подготовка, работа, отдых.

## Цель проекта

Создать интуитивно понятный и визуально приятный таймер для проведения высокоинтенсивных интервальных тренировок. Приложение помогает организовать тренировочный процесс без необходимости следить за временем вручную.

## Функциональность

- Выбор готовой программы тренировок или создание собственной
- Поддержка фаз: подготовка, работа, отдых, завершение
- Аудио сопровождение каждой фазы
- Отображение текущего этапа и раунда
- Реактивный интерфейс и адаптивная верстка

## Используемые технологии

- **React** + **React Router** — построение SPA и маршрутизация
- **Redux Toolkit** — управление состоянием таймера и загрузкой программ
- **JavaScript** — для создания функционала приложения
- **CSS Modules** — стилизация компонентов
- **HTML и CSS** для создания структуры и дизайна приложения;
- **Mock API** — получение тренировочных программ (через `mocki.io`)


## Описание компонентов

### **ContentArea.jsx**
- **Роль:** Отображает информацию на главной странице в зависимости от текущего маршрута. Использует данные из `PAGE_CONTENT` для вывода заголовка и описания, а также фоновое изображение для визуального оформления.

### **Footer.jsx**
- **Роль:** Отвечает за отображение футера на страницах приложения. Включает информацию о компании, ссылки на соцсети, дополнительные страницы и форму подписки на новости.

### **Header.jsx**
- **Роль:** Отображает шапку с логотипом и навигационными ссылками. Эти ссылки ведут на различные разделы сайта, такие как главная страница и страницы с тренировками для разных категорий (женщин и мужчин).

### **logo.jsx**
- **Роль:** Отображает логотип приложения, который состоит из графического элемента с часами и текста с названием "Tabata-таймер".

### **Root.jsx**
- **Роль:** Обеспечивает структуру главной страницы приложения, в том числе отображение шапки, основного контента и футера. Использует компонент `Outlet` для рендеринга динамичного контента в зависимости от маршрута.

### **Button.jsx**
- **Роль:** Обертка для кнопки, стилизованной с помощью CSS-модулей. Компонент принимает дочерние элементы и другие атрибуты, такие как `onClick`, для обработки событий.

### **Input.jsx**
- **Роль:** Компонент для отображения инпута с меткой. Используется для ввода времени тренировок, отдыха и количества раундов.

###  **Constants.jsx**
- **Роль:** Этот файл содержит константы, используемые в приложении. 
  - `PAGE_CONTENT` — объект с данными для различных страниц приложения, включая заголовок и описание для каждой страницы.
  - `AUDIO_LIST` — объект, который хранит пути к аудиофайлам для различных фаз таймера (подготовка, работа, отдых, конец), которые воспроизводятся во время тренировки.

### 2. **WorkoutTimerSlice.jsx**
- **Роль:** Этот файл управляет состоянием таймера и тренировок с помощью Redux Toolkit.
  - `initialState` — начальное состояние, которое включает в себя информацию о таймере, настройках тренировки, а также список программ тренировок.
  - `reducers` — различные функции для управления состоянием:
    - `startTimer`, `stopTimer`, `resetTimer`, `tick` — функции для управления таймером (старт, стоп, сброс, и обновление времени).
    - `setCustomTimer`, `selectProgram` — функции для установки кастомных настроек таймера или выбора программы тренировки.
  - `extraReducers` — обработки асинхронных действий для загрузки программ тренировок с помощью API.

### **Store.jsx**
- **Роль:** Этот файл настраивает Redux Store для приложения.
  - `configureStore` используется для настройки хранилища и интеграции с слайсом `workoutTimerSlice`, который управляет состоянием таймера и тренировок.

### **AudioPlayer.jsx**
- **Роль:** Управляет воспроизведением звуковых файлов для каждой фазы таймера.
- **Что делает:** Создает экземпляры аудио для каждой фазы (подготовка, работа, отдых, конец) и управляет их воспроизведением (play, pause, resume).
- **Что принимает:** 
  - `phase` — фаза таймера (`preparation`, `workout`, `rest`, `end`).
  - `action` — действие с аудио (`play`, `pause`, `resume`).

### **TabataTimer.jsx**
- **Роль:** Главный компонент, который отображает таймер и переключается между экраном выбора программы тренировки и экраном самого таймера.
- **Что делает:** Использует состояние `isStarted` для отображения компонента `InitialTimer` до начала тренировки и компонента `WorkoutTimer` после старта.

### **useWorkoutTimer.js**
- **Роль:** Хук для управления состоянием таймера.
- **Что делает:** Обрабатывает логику таймера, включая старт, стоп, сброс, тикание и форматирование времени. Обновляет состояние каждую секунду, если таймер активен.
- **Возвращает:** Обработчики для старта, паузы, сброса, форматирование времени и статус завершения тренировки.

### **WorkoutTimer.jsx**
- **Роль:** Отображает текущий статус тренировки, включая время, текущий раунд и фазу тренировки.
- **Что делает:** Использует данные из хука `useWorkoutTimer` для отображения времени, раундов и управления состоянием кнопок (пауза, продолжение, сброс).

### **InitialTimer.jsx**
- **Роль:** Экран для выбора программы тренировки или создания кастомной настройки таймера.
- **Что делает:** Загружает доступные программы тренировок, позволяет выбрать одну из них или настроить таймер вручную.

### **WorkoutDetails.jsx**
- **Роль:** Отображает детали выбранной программы тренировки.
- **Что делает:** Показывает информацию о тренировке (время работы, время отдыха, количество раундов) и позволяет начать тренировку.
- **Что принимает:** Получает выбранную программу тренировки из состояния Redux.

### **CustomTimer.jsx**
- **Роль:** Позволяет пользователю настроить свой собственный таймер для тренировки.
- **Что делает:** Предоставляет форму для настройки времени работы, отдыха и количества раундов, затем сохраняет настройки и запускает таймер.
- **Что принимает:** Значения времени работы, отдыха и раундов через форму ввода.

### **App.jsx**
- **Роль:** Главный компонент приложения, который отвечает за маршрутизацию.
- **Что делает:** Использует `createBrowserRouter` и `RouterProvider` из `react-router-dom` для маршрутизации между страницами:
  - `/` — главная страница с информацией о методе Табата.
  - `/tabata-timer` — страница с таймером Табата.
  - `/women-workouts` — страница с тренировками для женщин.
  - `/men-workouts` — страница с тренировками для мужчин.

### **main.jsx**
- **Роль:** Точка входа в приложение.
- **Что делает:** Рендерит приложение в DOM с использованием `createRoot` из `react-dom`. Оборачивает приложение в провайдер Redux для управления состоянием через `store`.
- **Что принимает:** Нет.

### **WomenWorkouts.jsx**
- **Роль:** Страница с тренировками для женщин.
- **Что делает:** Отображает список доступных программ тренировок для женщин, которые могут быть выбраны для выполнения.

### **MenWorkouts.jsx**
- **Роль:** Страница с тренировками для мужчин.
- **Что делает:** Отображает список доступных программ тренировок для мужчин, которые могут быть выбраны для выполнения.

### **AboutTabata.jsx**
- **Роль:** Страница с информацией о методе Табата.
- **Что делает:** Объясняет, что такое метод Табата, его преимущества и как правильно использовать таймер для выполнения тренировок.
